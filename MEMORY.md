# NightShift team memory

Kept by Keeper. Read first on every run; updated last, with the diff shown to the user before saving.
No secrets here: no keys, tokens, passwords, cookies or pairing codes.

## Team
- Starter bots (Phase 0 working names): Researcher, Builder, Reviewer, Keeper.
- Team file: `nightshift/team.yaml`; instructions in `nightshift/souls/`.
- Researcher runs on Claude Sonnet 5.5 (live WebSearch/WebFetch, read-only for code); Grok 4.7 is a one-line swap back in the team file when the user gets Grok.

## Conventions
- Research packets: `docs/research/<topic>-YYYY-MM-DD.md`
- Handoff packets: `docs/handoffs/<task-slug>.md`
- Builder works only on `feat/<task-slug>`; nothing is pushed, merged or deployed without the user's approval.
